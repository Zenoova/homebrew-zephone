# Homebrew tap for ZePhone

[ZePhone](https://github.com/Zenoova/ZePhone) is a universal SIP softphone.

```bash
brew tap zenoova/zephone
brew trust zenoova/zephone   # recent Homebrew versions refuse a third-party tap until it is trusted
brew install --cask zephone
```

The cask is updated automatically by the release workflow of ZePhone.
